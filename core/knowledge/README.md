# Knowledge Engine (/core/knowledge)

Este módulo gestiona la base de conocimiento estructurada del negocio.

## Componentes
*   **`knowledge-manager.ts`**: Motor de grafos de propiedades relacionales (Alpha Brain v1.0). Gestiona nodos y bordes para deducir conexiones contextuales de negocio.
*   **`academy-manager.ts`**: Recuperador de lecciones y manuales de procedimientos sembrados en la base de datos (RAG de Academia).
*   **`logging-engine.ts`**: Auditoría técnica inalterable del Core de IA (`AI_CORE_EXECUTE`).
