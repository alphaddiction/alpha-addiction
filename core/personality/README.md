# Personality Engine (/core/personality)

Este módulo gestiona la personalidad, el tono y la construcción del prompt del sistema para Alpha.

## Componentes
*   **`personality-engine.ts`**: Fuerza un tono refinado, minimalista y exclusivo (marca de lujo).
*   **`prompt-builder.ts`**: Ensambla dinámicamente el System Prompt final unificando la personalidad, el contexto actual de la sesión, los manuales de la academia relevantes, las vecindades del grafo y las reglas de seguridad.
