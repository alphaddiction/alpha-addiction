# Admin Application Portal (/apps/admin)

Este módulo representa el portal del panel de administración del negocio.

## Componentes y Vistas
1.  **Mission Control y Dashboard**: Resumen agregador de telemetría de ventas, pedidos y waitlist.
2.  **Health Center**: Diagnóstico operativo en tiempo real del estado de los servicios externos (PayPal, Printful, Resend) y persistencia técnica.
3.  **Knowledge & Memory Center**: Consolas de visualización y edición del grafo relacional del negocio (Alpha Brain) y del historial de conversaciones del asistente Alpha.
4.  **Alpha Chat Drawer**: Drawer flotante lateral para chatear con Alpha e interactuar en lenguaje natural con el sistema OMS.
