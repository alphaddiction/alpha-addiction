# Web Application (/apps/web)

Este módulo representa la aplicación web del e-commerce orientada al cliente.

## Funciones Principales
1.  **Catálogo y Ficha de Productos**: Vistas para explorar productos y variaciones de prendas minimalistas.
2.  **Checkout y Pasarelas de Pago**: Proceso de compra integrado con PayPal Checkout y cálculo automático de tasas mediante `/shared/models/orders`.
3.  **Waitlist de Drops**: Formulario de inscripción y validación para lanzamientos exclusivos de ropa.
